# FairSum — честно делим счёт

PWA-приложение для телефона (iPhone и Android): фотографируете счёт, отмечаете, кто что ел и пил, указываете чаевые и получаете, сколько должна каждая семья и кто кому переводит.

## Возможности

- **Справочник** семей и участников. Кто пришёл один, тот «семья» из одного человека.
- **Выбор участников** одним касанием по семье, отдельные люди включаются и выключаются. Есть кнопка «Те же, что в прошлый раз».
- **Распознавание счёта** прямо на телефоне (Tesseract.js, русский, румынский, английский). Позиции и итог можно поправить вручную, а сумма позиций сверяется с итогом на чеке.
- **Кто что ел:** по умолчанию позиция делится поровну на всех. Касание по имени исключает человека, а в «Поделить неравно…» для каждого задаётся доля штуками или дробью: хинкали 2 и 1, хачапури 1/4 и 3/4. Рядом сразу видно, сколько это в деньгах.
- **Чаевые** вводятся суммой, **обслуживание и скидка** — процентом или суммой. Всё это делится **пропорционально сумме каждой семьи**.
- **Кто платил:** одна семья оплатила весь счёт или несколько семей частями. Приложение считает минимальный набор переводов.
- **История** вечеров с удалением, **«Поделиться»** итогом в мессенджер.
- **Резервная копия** в JSON-файл и восстановление из неё.
- Работает **без интернета** после первого запуска. Данные хранятся только на телефоне.

## Как опубликовать (GitHub Pages, бесплатно)

PWA и камера требуют HTTPS, и GitHub Pages его даёт.

1. Создайте на GitHub репозиторий, например `FairSum`, и загрузите в него содержимое этой папки.
2. В репозитории откройте **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
3. Через минуту приложение откроется по адресу `https://<ваш-логин>.github.io/FairSum/`.
4. Откройте этот адрес на телефоне и установите приложение:
   - **iPhone (Safari):** «Поделиться» → «На экран „Домой“»;
   - **Android (Chrome):** ⋮ → «Установить приложение».

При первом распознавании скачиваются модуль распознавания и языковые файлы (около 20 МБ, один раз), поэтому лучше сделать это через Wi-Fi.

## Обновление приложения

После изменения файлов увеличьте `VERSION` в `sw.js`, например `fairsum-v2`. Телефоны получат новую версию при следующем запуске приложения.

## Разработка

```bash
npm test          # тесты расчёта и разбора чека (Node 18+)
npm start         # локальный сервер: http://localhost:8080
```

Структура:

| Файл | Назначение |
|---|---|
| `js/calc.js` | расчёт: доли, пропорциональные чаевые, переводы (в целых копейках, без ошибок округления) |
| `js/parse.js` | разбор распознанного текста чека в позиции |
| `js/ocr.js` | подготовка фото и распознавание через Tesseract.js |
| `js/store.js` | хранение данных в `localStorage` |
| `js/app.js` | интерфейс |
| `sw.js` | офлайн-режим |
